# Revora Business Rules

## Platform Type

Revora is a marketplace for second-hand fashion products.

Users can:

- Buy products
- Sell products
- Follow other users
- Like products
- Comment products
- Upload shorts

## Roles

Initial Roles:

- USER
- ADMIN

All registered accounts receive USER role.

## User Registration

Required:

- Username
- Email
- Password
- FullName

Email must be unique.

Username must be unique.

## First Login Reward

When a user logs in for the first time:

Grant:

- 2 free posting credits

The reward can only be received once.

## Product Ownership

Products belong to the creator.

Only:

- Product owner
- Admin

can update or delete products.

## Comment Ownership

Comments belong to the creator.

Only:

- Comment owner
- Admin

can delete comments.

## Credit Usage

Posting Credits:

Used when creating product listings.

Featured Credits:

Used when promoting products.

## User Status

Active users can:

- Login
- Post products
- Comment

Inactive users cannot access protected resources.

## Admin Permissions

Admins can:

- Manage users
- Manage products
- Manage categories
- Manage credit packages
- View transactions
